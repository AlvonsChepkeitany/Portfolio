
### Customization

To customize the proposal content, edit the `generate_proposal.py` file. The script is organized into methods for each section:

- `add_cover_page()` - Cover page content
- `add_executive_summary()` - Executive summary and highlights
- `add_objectives()` - Main and sub-objectives
- `add_technical_architecture()` - Architecture diagrams and tech stack
- `add_features()` - Feature listings
- `add_implementation_plan()` - Timeline and team structure
- `add_budget()` - Budget breakdown and revenue model
- `add_conclusion()` - Conclusion and next steps
